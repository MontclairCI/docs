<Steps>
  <Step title="1. Push changes" icon="git-pull-request-arrow">
    Trigger <Tooltip headline="What is a pipeline?" tip="TODO" cta="Learn more" href="/how-it-works/pipelines">pipelines</Tooltip> whenever new commits are pushed to your repository.
  </Step>
  <Step title="2. Build and test" icon="check">
    Run on a wide range of FreeBSD and Linux <Tooltip headline="What is a Docker image?" tip="A Docker image (or container image) is a standard format for packaging FreeBSD and Linux userspace software." cta="Learn more" href="/how-it-works/images">Docker images</Tooltip>.
  </Step>
  <Step title="3. Debug with SSH" icon="terminal">
    Connect to your CI execution environment with <Tooltip headline="How does SSH work?" tip="TODO" cta="Learn more" href="/how-it-works/ssh-access">SSH</Tooltip> to troubleshoot failures.
  </Step>
</Steps>

<h1 noAnchor>
  Run CI for FreeBSD and Linux
</h1>

Montclair CI supports custom <Tooltip headline="What is a Docker image?" tip="A Docker image (or container image) is a standard format for packaging FreeBSD and Linux userspace software." cta="Learn more" href="/how-it-works/images">Docker images</Tooltip> for FreeBSD and Linux.

<Columns cols={2}>
  <div>
    **Architectures**
    - `amd64`
    - `arm64`
  </div>
  <div>
    **Operating system kernels**
    - `FreeBSD 12+`
    - `Linux 4+`
  </div>
</Columns>

Windows and macOS runners are not supported.

<h1 noAnchor>
  Readability counts
</h1>

Montclair CI uses a <Tooltip headline="What configuration language is used?" tip="TODO" cta="Learn more" href="/">Python-like language</Tooltip> for defining CI pipelines. The pipeline language is

- **Expressive**, with native support for loops and conditionals
- **Maintainable**, with reusable functions, variables, and module imports
- **Guaranteed to terminate**, with static checking for unbounded loops and recursion

<Tabs>
  <Tab title="Matrix strategy">
    <CodeGroup>
```python pipeline.py
images = ["freebsd:14.4-RELEASE", "freebsd:15.1-RELEASE"]
arches = ["amd64", "arm64", "i686", "armv7"]

for image in images:
  for arch in arches:
      job(
        name = "test-{}-{}".format(image, arch),
        image = image,
        arch = arch,
        steps = ["make build", "make test"],
      )
```
    </CodeGroup>
  </Tab>

  <Tab title="Conditional jobs">
    <CodeGroup>
```python pipeline.py
if BRANCH == "main":
    job(name="deploy", steps=["make deploy"])
```
    </CodeGroup>
  </Tab>

  <Tab title="Functions and imports">
    <CodeGroup>
```python pipeline.py
# Import `clang_job` function from the `job_defs.py` file.
load("job_defs.py", "clang_job")

clang_job(name="sqlite", srcs=["sqlite.c"])
```

```python job_defs.py
def clang_job(name: str, srcs: list[str]):
  # Debug build
  job(
    name = "{}-debug".format(name),
    steps = ["clang -g3 -Og {}".format(" ".join(srcs))],
  )

  # Release build with optimizations
  job(
    name = "{}-release".format(name),
    steps = ["clang -flto -O3 {}".format(" ".join(srcs))],
  )

```
    </CodeGroup>
  </Tab>

</Tabs>

<h1 noAnchor>
  Stable prod begins with ergonomic dev
</h1>

The Montclair CLI (`montclair`) provides a toolbox for visualizing, validating, and debugging your CI pipelines.

<Tabs>
  <Tab title="Pipeline visualization">
    <CodeGroup>
```sh Interactive shell
$ montclair visualize
> [Graph visualization of the pipeline]
```
    </CodeGroup>
  </Tab>

  <Tab title="Static checking">
    <CodeGroup>
```sh Interactive shell
$ montclair check
> [Show cycles or misconfiguration]
```
    </CodeGroup>
  </Tab>
  
  <Tab title="SSH tunnel">
    <CodeGroup>
```sh Interactive shell
$ montclair ssh --job-id=1234
> Connecting to job-1234...
> Connected to job-1234. Type `exit` to disconnect.

root@job-1234:/$ ls -la
> bin  dev  home  lib  media  mnt  opt  proc  root  run  sbin  srv  sys  tmp  usr  var
```
    </CodeGroup>
  </Tab>
</Tabs>
